# i18nshaman API

NestJS backend for the i18nshaman localization workspace.

## Scripts

- `npm run start:dev` - start the development server with watch mode.
- `npm run build` - compile the API.
- `npm run start:prod` - run the compiled API from `dist`.

## Local Notes

- Runtime configuration is loaded from environment variables.
- API response conventions are documented in `API_CONTRACT.md`.
- Translation data ownership and lifecycle notes are documented in `DATA_MODEL.md`.
